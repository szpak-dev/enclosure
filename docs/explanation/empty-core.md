# Why Enclosure starts empty

A newly installed Enclosure instance knows how to govern. It does not pretend to
know an organization's constitution.

Records supply typed engineering knowledge. Operating contracts decide which
guidance is mandatory. Guidance scopes and relationships make optional knowledge
eligible for task routing. Scaffoldings package reusable source shapes. Architecture
configurations and accepted diagrams describe each project's intended structure.

Those are data because the organization owns them, not because they are arbitrary.
They carry schemas, revisions, provenance, and explicit bindings.

The empty core avoids shipping one company's process as universal truth. The cost
is honest: an operator must bootstrap useful records, contracts, scaffoldings, and
projects before the first governed workflow is available. Enclosure should make
that work reproducible; it should not hide it behind defaults that were never
accepted.
