# Task-specific context routing

Sending every organizational rule to every task creates a different failure: the
important instruction disappears inside a large, repetitive prompt.

Enclosure begins from the exact workspace binding. The project's active operating
contract contributes mandatory guidance. Project scopes define the optional
candidate records. The task's applicability, ranking, and fixed 4,096-character
optional-guidance budget determine which candidates are selected. Typed
relationships describe the effective guidance graph and participate in its
integrity checks; they do not add unscoped candidates.

The response carries a receipt:

- the authority and revision behind the effective contract;
- why each record was selected;
- coverage and omissions;
- budget use;
- diagnostics and the stop condition;
- the checks required before delivery.

Mandatory guidance is not ranked away by semantic similarity. Optional guidance
is not selected globally for the whole catalog. The workspace resolves the
project; selection belongs to that project and task, so two workspaces bound to
the same project receive the same selection for the same task and project state.

That makes context smaller without making it casual.
