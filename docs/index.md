# Enclosure documentation

The faster code is written, the more important it becomes to remember who said
yes.

Enclosure is a governance control plane for coding agents. It resolves a local
checkout to a registered project, selects the guidance relevant to the task,
checks implementation against accepted architecture, and returns evidence for a
human decision.

Start with the [dogfooding evidence](evidence/dogfooding.md) to see where the
system is already used. Continue with the
[first governed project](tutorials/first-governed-project.md) when an Enclosure
instance and a configured project are available.

Use the [how-to guides](how-to/index.md) for a specific task. The
[explanations](explanation/index.md) develop the ideas behind the product, while
the [architecture](architecture/index.md) records ownership and public seams.
The [reference](reference/index.md) contains exact configuration, interface,
contract, identifier, and compatibility details.

Documentation built from `main` describes unreleased development state.
Documentation built from a release tag describes that exact release.
